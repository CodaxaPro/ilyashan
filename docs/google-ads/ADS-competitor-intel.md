# Rakip istihbaratı — Aachen / Fensterreinigung

**Amaç:** Teklif ve mesajı körlemesine değil, SERP gerçekliğine göre ayarlamak.  
**Yenileme:** Her Wave açılışında + aylık.

---

## 1. Rakip tipleri

| Tip | Örnek | Tehdit | Bizim karşı hamle |
|-----|-------|--------|-------------------|
| Yerel tam hizmet temizlik | GMA Gebäudereinigung, EL-Cleaning | Geniş hizmet, yerel güven | **Uzmanlık:** yalnızca cam/pencere + canlı fiyat |
| Yerel pencere odaklı | Inmaculado (Stundenpreis ab 79–99 €/Std) | Saat ücreti belirsizliği | **Festpreis + Wizard** üstünlüğü |
| Portal / marketplace | MyHammer, BesteReinigung | SERP alanı, fiyat karşılaştırması | “Kein Vermittler · festes Team Baesweiler” |
| Ulusal zincir / lead gen | Çeşitli | Bütçe | QS + geo LP + call |
| DIY / içerik | Blog, YouTube | Bilgi tıklaması | Negatif kelimeler |

## 3. SERP denetim checklist (her geo)

Arama (incognito + konum spoof):

1. `fensterreinigung {stadt}`  
2. `fensterputzer {stadt}`  
3. `fensterreinigung preis {stadt}`  

Kaydet:

| Alan | Not |
|------|-----|
| LSA / Local Services var mı? | Evet/Hayır — varsa LSA başvuru değerlendir |
| Map Pack 3 | Kimler? GBP iyileştirme |
| Top Ads (1–4) | Başlık, USP, Final URL |
| Organik 1–5 | Kim? |
| Bizim organic sıra | |

## 4. Google Business Profile (zorunlu paralel kanal)

Ads üst sıra tek başına yetmez; Map Pack + arama birlikte çalışır.

- [ ] GBP kategori: Fensterreinigung / Glasreinigung  
- [ ] Hizmet alanları = Wave geo listesi  
- [ ] Fotoğraflar (önce/sonra)  
- [ ] Ürün/hizmet fiyat sinyali  
- [ ] Review yanıt hızı  
- [ ] UTM’li website = `ilyashan.de/de`  

LSA (Local Services Ads) Almanya’da uygun kategorideyse: ayrı lead maliyeti modeli — Search ile bütçe paylaşımı playbook’ta karara bağlanır.
